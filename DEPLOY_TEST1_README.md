# 🚀 Полностью Автоматическое Развертывание Тест #1

Этот файл содержит несколько способов автоматического развертывания Тест #1 в Google Sheet.

## ⚡ Быстрый старт

### Способ 1: Универсальный скрипт (РЕКОМЕНДУЕТСЯ)

```bash
python setup_and_deploy.py
```

Этот скрипт автоматически:
1. Проверит доступность требуемых инструментов
2. Установит необходимые компоненты (если нужно)
3. Выполнит развертывание
4. Добавит тест в Google Sheet

**Требует:** Python 3.6+

---

## 🔧 Подробные инструкции по каждому методу

### МЕТОД 1: Через Python + Google API

**Файл:** `deploy_test1_automated.py`

```bash
python deploy_test1_automated.py
```

**Требует:**
- Python 3.6+
- Библиотеки: `google-auth-oauthlib`, `google-auth-httplib2`, `google-api-python-client`
- Файл `credentials.json` с OAuth2 ключами

**Шаги установки:**

1. Установить библиотеки:
   ```bash
   pip install google-auth-oauthlib google-auth-httplib2 google-api-python-client
   ```

2. Получить `credentials.json`:
   - Перейти на https://console.cloud.google.com
   - Создать новый проект
   - Включить APIs:
     - Google Sheets API
     - Google Apps Script API
     - Google Drive API
   - Создать OAuth 2.0 Client ID (Desktop Application)
   - Скачать JSON файл и сохранить как `credentials.json`

3. Запустить скрипт:
   ```bash
   python deploy_test1_automated.py
   ```

---

### МЕТОД 2: Через Google Apps Script CLI (clasp)

**Файл:** `setup_and_deploy.py` (выберет этот метод автоматически)

```bash
python setup_and_deploy.py
```

**Требует:**
- Node.js 12+ и npm
- Google аккаунт

**Шаги:**

1. Установить Node.js с https://nodejs.org/

2. Скрипт автоматически установит clasp:
   ```bash
   npm install -g @google/clasp
   ```

3. Запустить развертывание:
   ```bash
   python setup_and_deploy.py
   ```
   или
   ```bash
   deploy_test1_auto.bat
   ```
   (для Windows)

---

### МЕТОД 3: Ручное развертывание через Google Sheets UI

**Файл:** Инструкции из `deploy_test1_auto.bat` или `setup_and_deploy.py`

**Шаги:**

1. Откройте Google Sheet:
   https://docs.google.com/spreadsheets/d/19BlhyKO3Wazo2b8ZxrqXpJKPm728CNrv9QBxURwKOKw/

2. Нажмите: **Расширения → Apps Script**

3. В редакторе Apps Script:
   - Выделите весь код в файле Code.gs (Ctrl+A)
   - Удалите его (Delete)
   - Откройте локально: `src/gas/Код.gs`
   - Скопируйте весь код из этого файла
   - Вставьте в Code.gs (Ctrl+V)

4. Нажмите кнопку **⚙️ Развернуть** → **Создать развёртывание**:
   - Выберите тип: **Веб-приложение**
   - Выполнять как: **[ваш Google аккаунт]**
   - Имеет доступ: **Я (только)**
   - Нажмите **Развернуть**

5. Скопируйте **URL развертывания** из диалога

6. Вернитесь в Google Sheet, обновите страницу (F5)
   Должно появиться меню: **🧪 Тесты**

7. Нажмите: **🧪 Тесты → ➕ Добавить ТЕСТ #1 (26 вопросов)**

8. Подтвердите в диалоговом окне

## 🆘 Если что-то не работает

### Ошибка: "Python не найден"
- Установите Python с https://www.python.org/
- Убедитесь, что Python добавлен в PATH
- Перезагрузите командную строку

### Ошибка: "Google API библиотеки не установлены"
```bash
pip install --upgrade google-auth-oauthlib google-auth-httplib2 google-api-python-client
```

### Ошибка: "Node.js не найден"
- Установите Node.js с https://nodejs.org/
- Перезагрузите командную строку
- Запустите скрипт заново

### Ошибка при аутентификации clasp
```bash
clasp logout
clasp login
```

### Ошибка: "Script не развернут"
Используйте Метод 3 (ручное развертывание) через Google Sheets UI

## 🔐 Безопасность

- **credentials.json** содержит чувствительные данные - не сохраняйте в Git
- **token.json** создается автоматически при первом запуске - не сохраняйте в Git
- Добавьте в `.gitignore`:
  ```
  credentials.json
  token.json
  .clasp.json
  ```
