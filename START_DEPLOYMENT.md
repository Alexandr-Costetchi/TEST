## 📊 Что произойдет

Скрипты автоматически попытаются выполнить следующее **в такой последовательности**:

### Попытка 1️⃣: Google Apps Script CLI (clasp)
- Установит clasp если нужно
- Отправит код в Google Apps Script
- Развернет приложение как веб-сервис
- **Требует:** Node.js, первоначальная аутентификация в Google

### Попытка 2️⃣: Google API (Python)
- Использует Google API для развертывания
- Требует файл `credentials.json` с OAuth ключами
- **Требует:** Python, Google API ключи

### Попытка 3️⃣: Ручное развертывание с инструкциями
- Откроет Google Sheet в браузере
- Покажет пошаговые инструкции
- Позволит развернуть вручную в Google Apps Script
- **Требует:** только браузер

## ⚙️ Установка требуемых компонентов

### Если нужен Node.js и clasp (РЕКОМЕНДУЕТСЯ)

1. **Установите Node.js:**
   - Windows: https://nodejs.org/ (скачайте LTS)
   - Mac: `brew install node`
   - Linux: `apt-get install nodejs npm` или `pacman -S nodejs npm`

2. **Перезагрузитесь или откройте новый терминал**

3. **Запустите скрипт развертывания:**
   ```bash
   python setup_and_deploy.py
   ```
   или
   ```cmd
   deploy_test1_auto.bat
   ```

### Если нужны Google API ключи

1. **Получите OAuth credentials:**
   - https://console.cloud.google.com/
   - Создайте новый проект
   - Включите: Google Sheets API, Apps Script API, Drive API
   - Создайте OAuth 2.0 Client ID (Desktop)
   - Скачайте JSON файл

2. **Сохраните файл:**
   ```
   Сохраните скачанный JSON как: credentials.json
   (в директорию где находится скрипт)
   ```

3. **Запустите скрипт:**
   ```bash
   python deploy_test1_automated.py
   ```
