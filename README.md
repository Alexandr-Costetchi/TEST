Современная архитектура для создания масштабируемой системы онлайн-тестов.

## Структура проекта


## Быстрый старт

### 1️⃣ Скопировать код в Google Apps Script

1. Откроем Google Sheet: https://docs.google.com/spreadsheets/d/1nP5GTP9sg8yqgOetbytOTYu5ahFfUOgVjw_NDl5Mi_A/
2. **Инструменты → Редактор Apps Script**
3. Скопировать содержимое файлов в соответствующие .gs файлы:
   - `Код.gs` → основной файл (заменить весь код)
   - `generateTestHTML.gs` → новый файл
   - `init_questions.gs` → новый файл

### 2️⃣ Инициализировать листы

1. В Google Sheet, меню **🧪 Тесты → 📋 Инициализировать листы**
2. Создадутся листы: "Вопросы", "Тесты", "Результаты теста"

### 3️⃣ Добавить вопросы теста 33

1. Отредактировать `init_questions.gs` - вставить 26 вопросов из документа
2. Запустить меню **🧪 Тесты → ➕ Добавить тест 33**

### 4️⃣ Получить ссылку на тест

Меню **🧪 Тесты → 🔗 Получить ссылку на тест 33**

## Ключевые особенности

✅ **Универсальный код** — одна система для всех тестов (32, 33, 34, ...)  
✅ **Данные в Google Sheets** — вопросы хранятся в таблице, не в коде  
✅ **Масштабируемость** — поддержка 100+ тестов без изменения скрипта  
✅ **Автоматическое сохранение результатов** — в лист "Результаты теста"  
✅ **Красивый интерфейс** — 3-экранный тест (приветствие → вопросы → результаты)  
✅ **Версионирование через Git** — все коды в проекте

## Как добавить новый тест

1. В лист "Тесты" добавить строку с метаданными теста
2. В лист "Вопросы" добавить все вопросы (testId, questionNum, text, options, correct, comment)
3. Запустить любую ссылку вида `?test=XXX` где XXX — ID теста
4. Код автоматически загрузит вопросы из листа

## Форматы данных

### Правильные ответы (JSON)
```
[1]           → один правильный ответ (опция 1)
[1,3]         → несколько правильных ответов (опции 1 и 3)
[2,4,5]       → три правильных ответа (опции 2, 4, 5)
```

## Развёртывание

Для публикации тестов:
1. Google Apps Script → **Развернуть → Новое развёртывание → Web app**
2. Выполнять как: ваш аккаунт
3. Доступно: любые пользователи
4. Получить URL

Тестовая ссылка: `https://script.google.com/.../exec?test=33`

## Проблемы и решения

### Ошибка "Лист не найден"
→ Запустить **🧪 Тесты → Инициализировать листы**

### Вопросы не загружаются
→ Проверить лист "Вопросы" — есть ли вопросы с нужным ID теста

### Результаты не сохраняются
→ Проверить права доступа к Google Sheet в Google Apps Script
