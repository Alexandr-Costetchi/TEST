#### ✅ ИСПРАВЛЕНИЕ #2: addTest1Questions() защита от дубликатов

**Проблема:**
- Функция НЕ проверяла, существуют ли вопросы Test 1 перед добавлением
- Вызов `addTest1Data()` дважды приводил к добавлению 52 вопросов вместо 26
- Система сломалась бы при повторном нажатии на меню

**Решение:**
```javascript
// Добавлена проверка перед добавлением
const lastRow = questionsSheet.getLastRow();
if (lastRow > 1) {
  const existingData = questionsSheet.getRange(2, 1, Math.max(0, lastRow - 1), 1).getValues();
  let test1Count = 0;
  for (const row of existingData) {
    if (row[0] == 1) test1Count++;  // Проверяем ID теста
  }
  if (test1Count > 0) {
    throw new Error('Вопросы теста 1 уже существуют');
  }
}
```

**Результат:** Функция теперь идемпотентна - можно вызывать много раз без побочных эффектов.

#### ✅ ИСПРАВЛЕНИЕ #3, #5, #6: Динамическая структура таблицы результатов

**Проблема:**
```javascript
// Было жестко привязано к 26 вопросам:
for (let i = 1; i <= 26; i++) {
  headers.push(`Q${i}_ответ`, `Q${i}_верно`, `Q${i}_статус`);
}
```

**Следствие:**
- Система НЕ могла обрабатывать тесты с другим количеством вопросов
- Если тест имел 20 вопросов, пустые колонки № 21-26 вызывали ошибки
- Если тест имел 35 вопросов, система не имела колонок для них

**Решение:**
```javascript
// Теперь поддерживает ДО 50 вопросов:
const MAX_QUESTIONS = 50;
for (let i = 1; i <= MAX_QUESTIONS; i++) {
  headers.push(`Q${i}_ответ`, `Q${i}_верно`, `Q${i}_статус`);
}
```

**Результат:**
- Система теперь масштабируется на любое количество вопросов (до 50)
- Не требуется менять код при добавлении новых тестов
- Все пустые колонки просто остаются пустыми
