## 📝 Формат данных

### JSON структура вопроса:
```json
{
  "test_id": 31,
  "question_id": 1,
  "question_text": "Текст вопроса...",
  "options": "[\"Вариант 1\", \"Вариант 2\", ...]",
  "correct_answers": "[1, 3]",
  "timestamp": "2026-05-22T12:47:58.776519"
}
```

### Таблица Google Sheet:
- **Лист "Архив"**: Метаданные тестов (ID, название, темы, URL)
- **Лист "Вопросы"**: Вопросы с вариантами ответов (10 колонок)
- **Лист "Результаты теста"**: Результаты студентов

## 🚀 Использование

### Импорт в Google Sheet:
1. Откройте Google Apps Script в таблице
2. В меню выберите: 🧪 Тесты → ➕ Добавить тесты 3.1-3.5
3. Дождитесь уведомления об успехе

### Добавление нового теста:
1. Создайте HTML файл с тестом (с QUESTIONS массивом)
2. Запустите скрипт экспорта: `python add_tests_to_sheet.py`
3. Проверьте `tests/exported/` для JSON файла
4. Коммитьте и синхронизируйте

## 📋 Git команды
