# 📱 Мобильный Player для тестов

## Что это?
`mobile-test-player.html` — полностью мобильная версия интерфейса для прохождения тестов на телефоне.

## Возможности
✅ **Полностью адаптивный дизайн** для всех размеров экранов  
✅ **Сенсорный интерфейс** с крупными кнопками  
✅ **Поддержка iPhone и Android** (PWA готово)  
✅ **Автоматическая загрузка тестов** из JSON  
✅ **Отслеживание прогресса** с визуальной полосой  
✅ **Вычисление результатов** с процентом правильных ответов  
✅ **Поддержка темы экрана** (light/dark)  
✅ **Оптимизация для выемок** (notch) на новых телефонах  

## Как использовать

### Вариант 1: Локально на компьютере
1. Откройте файл `mobile-test-player.html` в браузере
2. Мобильный плеер автоматически загрузит тесты из `exported/tests_31_35_sociologiya.json`
3. Выберите тест и начните прохождение

### Вариант 2: На телефоне через QR код
1. Разместите файл на веб-сайте (verny-kurs.ru)
2. Создайте QR код со ссылкой
3. Пользователи отсканируют QR и будут перенаправлены на тест

### Вариант 3: Как PWA (Progressive Web App)
При открытии на мобильном браузере iOS/Android будет предложение:
- "Добавить на главный экран" (iPhone)
- "Установить приложение" (Android)

## Особенности дизайна

### Для мобильных устройств:
- **Шрифты**: Крупные, легко читать на маленьких экранах
- **Кнопки**: 44x44px минимум (стандарт Apple)
- **Промежутки**: Достаточные для удобного касания пальцем
- **Цвета**: Контрастные, подходят для солнечного света
- **Анимации**: Быстрые, но приятные (не раздражающие)

### Для iOS (iPhone/iPad):
- `viewport-fit=cover` для полноэкранного режима
- `apple-mobile-web-app-capable: yes` для добавления на главный экран
- Отступы для выемки (notch) автоматические

### Для Android:
- `theme-color` для цвета статус-бара
- Поддержка PWA установки
- Material Design цвета (фиолетовый градиент)

## Как развернуть на сайте

### Шаг 1: Скопировать на сайт
```bash
# Скопировать файл и папку tests на вебсервер
cp tests/mobile-test-player.html /var/www/html/tests/
cp -r tests/exported /var/www/html/tests/
```

### Шаг 2: Доступ по URL
```
https://verny-kurs.ru/tests/mobile-test-player.html
```

### Шаг 3: Создать интерфейс выбора
Создайте простую страницу с кнопками:
```html
<a href="/tests/mobile-test-player.html" class="btn">
  📱 Решать тесты на телефоне
</a>
```

## Тестирование

### На компьютере:
1. Откройте Developer Tools (F12)
2. Переключитесь в Device Emulation (Ctrl+Shift+M)
3. Выберите мобильное устройство (iPhone 12, Pixel 5, и т.д.)
4. Протестируйте все экраны

### На реальном телефоне:
1. Откройте в браузере (Chrome, Safari, Firefox)
2. Проверьте касание всех кнопок
3. Проверьте скролл при длинных вопросах
4. Проверьте поворот экрана (portrait/landscape)
