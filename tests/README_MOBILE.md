# 📱 Мобильные Тесты ЕГЭ

## 🎯 Быстрый старт

### Открыть тесты на телефоне локально:
1. Скопируйте папку `tests/` на телефон (через USB или облако)
2. Откройте файл `mobile-test-player.html` в браузере
3. Начните решать тесты!

### Открыть онлайн:
```
GitHub: https://github.com/Alexandr-Costetchi/TEST/blob/master/tests/mobile-test-player.html
Веб-сайт: https://verny-kurs.ru/tests/mobile-test-player.html (когда развернется)
```

## ✨ Основные возможности

### 1. Адаптивный дизайн
- ✅ Работает на всех размерах экранов
- ✅ Оптимизирован для мобильных устройств
- ✅ Поддерживает темный режим браузера
- ✅ Работает с выемками на новых телефонах

### 2. Удобный интерфейс
- ✅ Крупные кнопки для сенсорного управления (44x44px)
- ✅ Визуальная полоса прогресса
- ✅ Красивые градиенты и анимации
- ✅ Четкая типография на маленьких экранах

### 3. Интерактивность
- ✅ Выбор нескольких ответов (чекбоксы)
- ✅ Навигация вперед/назад между вопросами
- ✅ Автоматическое сохранение ответов
- ✅ Быстрые переходы между экранами

### 4. Результаты
- ✅ Автоматический расчет процента правильных ответов
- ✅ Подробная статистика прохождения
- ✅ Время, затраченное на тест
- ✅ Мотивирующие сообщения по результатам

## 🚀 Как использовать

### На мобильном браузере (iPhone):

1. **Откройте сафари** и перейдите на страницу с плеером
2. **Нажмите кнопку Share** (⬆️)
3. **Выберите "Add to Home Screen"** (Добавить на главный экран)
4. **Назовите приложение** (например, "Тесты ЕГЭ")
5. **Нажмите Add** — теперь это как приложение!

### На мобильном браузере (Android):

1. **Откройте Chrome** и перейдите на страницу
2. **Нажмите меню** (⋮)
3. **Выберите "Install app"** или "Add to Home Screen"
4. **Подтвердите** — приложение установлено!

### На компьютере:

1. **Откройте файл** в браузере (правый клик → Open with Browser)
2. **Нажмите F12** чтобы открыть Developer Tools
3. **Переключитесь на мобильный вид** (Ctrl+Shift+M)
4. **Выберите устройство** (iPhone 12, Pixel 5 и т.д.)
5. **Тестируйте!**

## 🐛 Решение проблем

### Проблема: Тесты не загружаются
**Решение**: Проверьте, что файл JSON находится в папке `exported/` рядом с плеером

### Проблема: Кнопки маленькие на мобильном
**Решение**: Это нормально - размер 44x44px оптимален для пальца

### Проблема: Медленная загрузка
**Решение**: Проверьте скорость интернета - тесты весят ~100 KB

### Проблема: Результаты не сохраняются
**Решение**: Это нормально - результаты вычисляются при завершении теста
